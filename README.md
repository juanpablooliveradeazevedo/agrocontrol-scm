# AgroControl 🌱

Protótipo acadêmico desenvolvido em Python para prática de **Gerenciamento de Configuração de Software (SCM)**, versionamento e utilização do **Git/GitHub** durante a graduação em Análise e Desenvolvimento de Sistemas.

## 📌 Objetivo

O projeto foi criado como atividade acadêmica para exercitar conceitos de gerenciamento de configuração e evolução de software.

A aplicação simula o início de um sistema de gestão agrícola e contém uma funcionalidade simples para registro de propriedades rurais.

## ⚙️ Funcionalidades atuais

- Inicialização do protótipo AgroControl
- Identificação da versão da aplicação
- Simulação de módulo de propriedades rurais
- Função para registrar uma propriedade
- Evolução do projeto por meio de commits no Git

## 🛠️ Tecnologias utilizadas

- Python
- Git
- GitHub
