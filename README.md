### [AgroControl](https://github.com/juanpablooliveradeazevedo/agrocontrole-scm)

Protótipo acadêmico em Python desenvolvido para prática de Git, GitHub e Gerenciamento de Configuração de Software durante a graduação em Análise e Desenvolvimento de Sistemas.

Projeto utilizado para praticar controle de versões, commits e evolução incremental de software.

## 📌 Objetivo

O projeto foi criado como atividade acadêmica para exercitar conceitos de gerenciamento de configuração e evolução de software.

A aplicação simula o início de um sistema de gestão agrícola e contém uma funcionalidade simples para registro de propriedades rurais.

## ⚙️ Funcionalidades atuais

- Inicialização do protótipo AgroControl
- Identificação da versão da aplicação
- Simulação de módulo de propriedades rurais
- Função para registrar uma propriedade
- Evolução do projeto por meio de commits no Git

## 🛠️ Tecnologias utilizadas

- Python
- Git
- GitHub

## 📂 Estrutura do projeto

```text
agrocontrole-scm/
├── app.py
├── nova_funcionalidade.py
└── README.md
```

### `app.py`

Arquivo principal do protótipo.

Apresenta informações sobre a aplicação e indica a disponibilidade do módulo de propriedades rurais.

### `nova_funcionalidade.py`

Exemplo de evolução do projeto contendo uma função simples para registrar uma propriedade rural.

## ▶️ Como executar

É necessário ter o Python instalado.

Para executar o arquivo principal:

```bash
python app.py
```

Para testar a funcionalidade de registro:

```bash
python nova_funcionalidade.py
```
